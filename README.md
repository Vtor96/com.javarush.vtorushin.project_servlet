# Tic-Tac-Toe — игра «Крестики-Нолики» на сервлетах и JSP

Учебный проект для курса JavaRush (модуль «Java Professional»). 
Веб-игра «Крестики-Нолики» с противником-AI. 
Состояние игры хранится в HTTP-сессии, отрисовка — через JSP + JSTL, взаимодействие — через сервлеты.

## Функционал

- Поле 3×3, клик по ячейке — ход крестиком.
- AI отвечает ноликом в первую свободную ячейку.
- Проверка победы: 8 выигрышных комбинаций (3 ряда, 3 столбца, 2 диагонали).
- Обработка ничьей (нет пустых ячеек, никто не победил).
- Кнопка «Start again» — сброс сессии и новая игра.
- Защита от хода в занятую ячейку.
- Состояние игры хранится в `HttpSession` между запросами.

## Стек

- Java 18
- Servlet API 4.0
- JSP + JSTL
- jQuery 3.6 (перезапуск игры через AJAX)
- Maven 3 (сборка WAR)
- Apache Tomcat 9

## Требования

- JDK 18+
- Maven 3.6+
- Apache Tomcat 9.0.x

## Как запустить

1. Соберите проект: `mvn clean package`.
2. Деплойте WAR в Tomcat 9 (через IDE или копированием в `webapps/`).
3. Откройте в браузере: `http://localhost:8080/start`.

Альтернативно — настройте Tomcat 9 в IntelliJ IDEA (Run Configuration → Tomcat Local → Deployment → `tic-tac-toe:war exploded` → Application context: `/`).

## Архитектура

| Сервлет | URL | Метод | Назначение |
|---------|-----|-------|-----------|
| `InitServlet` | `/start` | GET | Создаёт сессию, поле, форвард на `index.jsp` |
| `LogicServlet` | `/logic` | GET | Ход игрока → ответ AI → проверка победы/ничьей |
| `RestartServlet` | `/restart` | POST | Инвалидирует сессию, редирект на `/start` |

## Поток игры

1. Пользователь открывает `/start` → создаётся сессия с пустым полем.
2. Клик по ячейке → GET `/logic?click=N` → крестик в ячейку N.
3. AI ставит нолик в первую свободную ячейку.
4. Проверка победы: если есть линия — в сессию пишется `winner`, редирект.
5. Если пустых ячеек нет и нет победителя — в сессию пишется `draw`.
6. `index.jsp` отрисовывает поле из `${data}` и показывает результат.
7. Кнопка «Start again» → POST `/restart` → сессия сбрасывается, новая игра.
